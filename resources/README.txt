resources/ 目录说明
==================

此目录用于存放项目开发中用到的辅助资源文件，包括但不限于：

1. 知识库文件
   - 领域知识文档（.md / .txt / .pdf）
   - 技术规范文档
   - API 参考资料

2. 数据文件
   - 测试数据集（.csv / .json / .yaml）
   - 配置文件样本
   - 日志样本文件

3. 模型与权重（如适用）
   - 预训练模型文件
   - 微调后的权重文件
   - Prompt 模板文件（.txt / .json）

4. 图片与截图
   - 架构图（.png / .svg）
   - 运行效果截图
   - UI 设计稿

5. 演示资源
   - 演示视频（或视频链接记录在 txt 中）
   - Demo 录屏
