EviMend 验证资源
================

source-validation/ 保存现有宿主源码回放运行器、适用范围说明和独立软件样例。
example/ 是不依赖原数据的 JavaScript 示例；其余运行器绑定各自的语义范围，
不能作为任意程序或完整应用的通用模拟器。原始源码与故障数据不包含于本目录。

preparation/case-oracles.json 是现有观察检查与回归测试使用的元数据。
旧全量数据盘点和资料索引保存在 dfx-agent-v1.0 快照，不作为当前研究计划。

新增资源先确定它服务的任务、源码版本、输入、判据与许可。
不要保存模型 Key、本机环境、参考答案到求解器可读取的知识入口。
研究实验的正式样本、隐藏判据和发布证据应分别明确边界。
