skill/ 目录说明
===============

此目录用于存放项目定义的 Skill（技能/能力模块），包括但不限于：

1. Skill 定义文件
   - SKILL.md：技能描述、工作流步骤、输入输出规范

2. 技能脚本
   - 技能执行所需的核心脚本
   - 数据处理和分析工具

3. 参考资料
   - 技能依赖的领域知识文档
   - 故障模式库 / 诊断规则库
   - API 参考文档

4. 技能测试
   - 技能级别的测试用例
   - 技能输出的验证脚本



注意：
- 每个 Skill 独立一个子目录
- SKILL.md 是技能的核心描述文件
- 脚本和参考资料分别放在 scripts/ 和 references/ 子目录中
